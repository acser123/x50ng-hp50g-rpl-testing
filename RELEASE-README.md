# x50ng HP 50g RPL test environment — source release candidate

This package contains modified x50ng source code and RPL testing scripts extracted from the user's working Linux project.

Upstream: https://codeberg.org/gwh/x50ng
License: See source/LICENSE (GPL-2.0); preserve original notices and applicable bundled licenses.

IMPORTANT: No HP firmware, ROM images, emulator state, or prebuilt Linux binaries are included. Obtain any required firmware separately from a lawful source.

The original local testing setup used RPN mode, virtual SD .49G string imports, →OBJ conversion, and keyboard-driven execution. Verified local examples included 1 1 + = 2, Fibonacci(15) = 610, and the NiMH battery tester 80 mOhm GOOD. These results do not constitute a clean-build test of this source-only release.

Before publishing, review the source and scripts for private paths, bundled third-party licenses, and reproducibility.

# x50ng HP 50g User RPL testing (release staging)

This repository is being prepared as a source-only distribution of modifications to [x50ng](https://codeberg.org/gwh/x50ng).

**Status: INCOMPLETE SOURCE UPLOAD — not yet buildable from this repository.** The complete modified emulator source has not been uploaded. Do not treat this repository as a verified release.

## Intended features
- Virtual SD import of HP 50g .49G string objects
- RPN-mode verification and keyboard-driven User RPL tests
- Test cases: `1 1 + = 2`, Fibonacci(15) = 610, and a four-field NiMH battery internal resistance tester (80 mOhm, GOOD)

## Firmware
HP calculator firmware, ROM images, emulator state, and prebuilt binaries are intentionally **not** distributed. Users must obtain required firmware from lawful sources.
